issue: 1006
bump: patch

The idle rest-timer control on the Log screen is now a compact stopwatch in
the corner of the current-routine editor instead of a full-width row that
floated well above the bottom navigation. Tapping it reveals the same 60,
90, 120, and 180 second choices; tapping one starts that timer and closes
the chooser. The control only appears while editing the current routine and
no timer is running, and it no longer reserves bottom-navigation clearance.
The running countdown and completion banner are unchanged.
