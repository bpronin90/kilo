bump: patch

Normalize exercise names no longer sends your workout history. The prompt now shares only the authoritative routine's exercise names and each distinct exercise header from the routines you select (for example "-Single-Leg RDL 2x8 each leg, light"), with a numbered reference and the day or section it appears in. Logged sets, weights, dates and comments stay on your device, and Kilo applies each accepted change itself from your saved routines, moving any extra header text into a "-- " note after that exercise's sets. The reply is now one short line per header, and a reply that doesn't follow that format is rejected as a whole. A prompt saved by an earlier version can no longer be imported; copy a new prompt or discard the old one.
