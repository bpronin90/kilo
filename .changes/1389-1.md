Normalize exercise names replies are now easier to copy and fix. The prompt asks the LLM to answer in one code block, so tapping Copy in ChatGPT or Claude keeps every line break, and Kilo accepts a reply wrapped in one code block. If the line breaks are lost, Kilo shows one clear message instead of a long list of errors, and runs of missing replies are grouped (for example H1–H72). The error list can be selected, and a new Copy fix-up message button copies every problem with a short instruction you can paste back to the LLM.
