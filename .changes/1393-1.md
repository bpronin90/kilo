Tracking or untracking an exercise now syncs to the cloud right away instead of waiting for an unrelated save or relaunch. If that sync fails, the sync status shows the failure and a retry uploads the change. Several quick Track taps in a row now keep your final choice. A Track change, profile setting, or other synced setting changed while a sync is already running is no longer reverted when that sync finishes; the next sync uploads it.
