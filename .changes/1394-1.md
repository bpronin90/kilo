Normalize exercise names now treats anything after a header's prescription as a descriptor. An authoritative header like `-Single-Leg RDL 2x8 each leg` now offers the name `Single-Leg RDL`, so a routine header like `-Single-Leg RDL 2x8 each leg, light` can be normalized to `-Single-Leg RDL 2x8` with `-- each leg, light` moved into a comment, instead of being rejected because numbers would be dropped. Numbers that belong to a name before the prescription (such as `Squat 5/3/1`) are kept. A prompt copied before this update whose authoritative names changed asks you to generate a fresh prompt.
