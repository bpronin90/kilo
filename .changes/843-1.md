Redesigned the Log tab's Recovery and Routine sub-tabs. Recovery's active
block now renders as one grouped card with a state zone, an aligned week
table (status carried by a dot, no more per-row "In progress"/"Completed"
text), and a single primary action ("Complete Week N" or "Add week"). A
sibling "Manage block" card holds the analytics-inclusion setting, Unlink,
and End recovery block, which now opens a dedicated confirmation modal
instead of a plain alert — inclusion is preselected from the block's current
setting and can still be changed before confirming. The current routine card
uses a CURRENT badge and a single accent top rail instead of an all-round
border, with Edit/Week A-B/Skip in one control row. More Routines always
shows "More Routines · {count}" and a New routine control outside the
disclosure, with a flat divided row list inside it.
