bump: patch

Added an explicit kg marker for workout-note weights (e.g. "40kg 10" or
"40 kg 10"), so a load recorded on a kg-only machine at another gym folds
into your normal lb progression. The set is shown as a whole-lb value with a
visible note that it was converted, in both the note view and exercise
history/progress. A bare weight number is unchanged: it still means lb, and
your saved notes are never rewritten.
