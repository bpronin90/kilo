Workout parsing now follows the owner-approved F2a grammar contract. Bodyweight
sets accept a skipped-set marker ("3,3,-"), trailing commas and ranges get
specific correction messages instead of generic ones, and a bare integer under
a "3x30 sec"/"3x6-8"-style exercise header now logs as one set of the declared
duration or reps. Cardio/non-weight exercises log ordinary structured sets like
any other exercise, but stay out of tonnage, PR/max, and rep-drop-off
calculations. A "-- " comment or any other nonblank line with no matching
structured meaning is preserved and visible in the read view instead of being
silently dropped, and prose typed directly as a set row is pointed at the
"-- " comment syntax instead of the reps grammar it wasn't using.
