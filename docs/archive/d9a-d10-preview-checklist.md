# D9a/D10 Preview Validation Checklist

## 1. New user / empty Log

- [ ] Create a routine.
- [ ] Confirm it does not automatically replace the current routine.
- [ ] Confirm the prompt offers `Use as current` and `Not now`.
- [ ] Tap `Not now` and confirm there is still an obvious way to adopt it later.
- [ ] Confirm the syntax example explains that each new line is a new session.
- [ ] Confirm bodyweight entries are explained.

## 2. Guided entry and autofill

- [ ] Create a routine through the guided flow.
- [ ] Edit, cancel, and use the plain-text escape.
- [ ] Copy a previous session and confirm the preview is accurate before applying it.
- [ ] Confirm skipped or older sessions are labeled honestly, such as `from 2 sessions ago`.
- [ ] Try duplicate exercise names.

## 3. Existing routine safety

- [ ] With a current routine, save another routine.
- [ ] Confirm the current routine stays current.
- [ ] Press `Use as current`, then cancel or dismiss the confirmation.
- [ ] Confirm nothing switches and the prompt remains available.
- [ ] Test `Save & Switch` with edits, then dismiss the rollover confirmation.
- [ ] Confirm edits remain saved but the routine does not switch.

## 4. Fatigue check-in

- [ ] Finish a genuinely degraded session with `Done`; a prompt may appear.
- [ ] Switch tabs mid-edit; confirm no prompt appears.
- [ ] Press `Skip week`; confirm no fatigue prompt appears.
- [ ] Log normal straight sets with a small rep drop; confirm no prompt appears.
- [ ] Rename the routine to `Deload · ...` and press `Done`; confirm no fatigue prompt appears.
- [ ] Trigger one prompt, then confirm the next two rough sessions do not interrupt you.

## 5. Basic quality

- [ ] Test 320dp, 375dp, and 448dp widths.
- [ ] Test large text.
- [ ] Verify TalkBack/VoiceOver labels and focus order.
- [ ] Confirm loading and error states do not show misleading empty guidance.
- [ ] Confirm existing routines, notes, and current-routine selection remain intact.

## Preview details

- Preview channel: `preview`
- Android runtime: `preview-4`
- Expected app version after the 0.103.0 OTA: `0.103.0`
